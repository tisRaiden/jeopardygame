to use this game, pleas visit this link:
https://tisraiden.github.io/jeopardygame/

the controls are very simple the game can be completed and changed entirely in the browser.

to begin editing please click the "edit" button<br>
you can then change the title of the game<br>
click the questions to view the editable options for those<br>
you are also able to change the colours of the teams<br>
finally you can change the style (look) of the game<br>

adding and removing rows and categories is at the top while editing<br>
along with the option to change tha mount of teams<br>
and randomizing the 2 daily doubles<br>

finally once you have made all the changes please click play<br>
if you wish to return to the game please save the file<br>
to return to the game you can load the JSON file that you downloaded in the previous step<br>

----------------

if you wish, you can edit all question directly from the JSON file and template will be provided<br>
change "q" for question<br>
change "a" for answer<br>
change "dd" to true or false to enable or disable the daily double<br>

----------------

Note:<br>
If a team other than team 1 is starting please click anywhere in the box to select that team<br>

otherwise the game will function just like jeopardy!
