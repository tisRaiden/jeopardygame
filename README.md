to use this game, pleas visit this link:
https://tisraiden.github.io/jeopardygame/

the controls are very simple the game can be completed and changed entirely in the browser.

to begin editing please click the "edit" button
you can then change the title of the game
click the questions to view the editable options for those
you are also able to change the colours of the teams
finally you can change the style (look) of the game

adding and removing rows and categories is at the top while editing
along with the option to change tha mount of teams
and randomizing the 2 daily doubles

finally once you have made all the changes please click play
if you wish to return to the game please save the file
to return to the game you can load the JSON file that you downloaded in the previous step

----------------

if you wish, you can edit all question directly from the JSON file and template will be provided
change "q" for question
change "a" for answer
change "dd" to true or false to enable or disable the daily double
